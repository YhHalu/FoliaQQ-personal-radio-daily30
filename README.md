# FoliaQQ音乐个性电台和每日三十首

Folium 模组，适配 Folia **0.7.16** 和内置 QQ API **3.1.3**。

## 使用

1. 在 Folia 的模组管理中启用「QQ 每日30首与个性电台」，确认应用自己的启用提示。
2. 在 Folia 登录 QQ 音乐，切换到 QQ 音乐的歌单列表。
3. 原有歌单后会多出 **每日30首** 和 **个性电台** 两个入口。
4. 每日30首使用原有歌曲列表，可选歌播放；个性电台使用原有 FM 播放流程，队列接近末尾时继续取歌。

它们是模组生成的独立入口，类型分别为日推和电台。没有在 QQ 音乐账号里创建、收藏或修改歌单，也没有混入导入歌单的持久数据。停用模组后，这两个入口移除，原有歌单保留。

安装：将仓库中的 main.cjs、backend.cjs、client.mjs、bridge.mjs、mod.json 和说明文件放入 Folia 用户模组目录下的 qq-personal 文件夹。当前仓库提供源码，尚未发布 Release ZIP。升级 Folia 后，版本锁会阻止不兼容版本加载，需重新核对内部接口。

## 多账号

从 Folia 当前登录的 QQ 会话中取数据，没有内置 QQ 号、歌单 ID 或登录凭据。切换 QQ/微信登录账号后自动读取新账号的推荐入口。

每次请求同时校验会话和账号；返回时再次确认会话仍有效。前端按账号、会话、北京时间日期隔离缓存，旧账号的迟到请求不会填入新账号页面。未登录不显示两个入口，登录失效按错误处理，不改用匿名推荐。

每日30首的虚拟列表 ID 包含账号和日期，避免复用宿主其他账号/其他日期的列表资源。电台最近 300 个歌曲 MID 在内存中去重，连续 3 批没有新歌曲时停止请求，不无限重试。

## 实现与范围

- main.cjs：复用正在运行的 QQ 后端会话管理器，注册模组 RPC。
- backend.cjs：认证、每日入口发现、歌单分页、电台请求以及响应字段白名单。
- client.mjs / bridge.mjs：通过版本锁定的宿主注册表接入 QQ 推荐能力，在原歌单列表投影两个虚拟入口；保留原始 library、catalog、播放和歌词实现。
- 不开启独立 HTTP 服务，不解密磁盘配置，不存储会话，不附带开发阶段的私人歌单导出结果。
- 没有修改 Folia 安装包。停用时恢复被包装的宿主方法和原 QQ provider，并清除模组定时器与内存缓存。
- 播放沿用 QQ 音乐账号已有权限；本轮验证了推荐列表获取，未进行音频播放或会员音质测试。

宿主公开模组接口尚不直接开放完整推荐注册，本版本使用声明版本范围的内部接口，并依赖 0.7.16 的 providerRegistry-CFhm3rDN.js。不能将它视为跨 Folia 版本通用包。
